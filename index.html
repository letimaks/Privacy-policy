Політика конфіденційності

Дата набрання чинності: 10 листопада 2026 року

Ця Політика пояснює, які дані використовує розширення «Арава ВНАУ», з якою метою та як вони обробляються.

01 Як працює розширення

«Арава ВНАУ» допомагає отримувати відповіді штучного інтелекту на основі тексту вебсторінки. Користувач виділяє текст і запускає обробку доступним способом — через гарячу клавішу або контекстне меню. Якщо відповідна функція ввімкнена, розширення також може використовувати текст сторінки.

02 Які дані обробляються

  • Текст вебсторінки: виділений користувачем фрагмент або текст сторінки, якщо користувач увімкнув і використовує таку функцію.
  • Ключ API Groq: якщо користувач налаштував власний ключ, він використовується для авторизації запиту до Groq.
  • Налаштування розширення: параметри вигляду вікна, прозорості, гарячих клавіш та інші параметри, потрібні для роботи.

03 Передавання даних третім сторонам

Коли користувач запускає AI-запит, відповідний текст передається до API сервісу Groq для обробки та формування відповіді. Ключ API, якщо він використовується, передається Groq як облікові дані авторизації запиту.

Обробка даних сервісом Groq регулюється його власними умовами та політикою конфіденційності: Політика конфіденційності Groq.

Не надсилайте через розширення паролі, платіжні реквізити, медичні відомості або іншу конфіденційну інформацію, якщо не бажаєте передавати її зовнішньому AI-сервісу.

04 Локальне зберігання

Налаштування розширення та введений користувачем ключ API можуть зберігатися у сховищі браузера Chrome, щоб зберігати конфігурацію між запусками. Не використовуйте спільний або ненадійний профіль браузера для зберігання власного API-ключа. Локальне зберігання в браузері не слід вважати захищеним сховищем секретів.

05 Мета використання даних

Дані використовуються для виконання запиту, отримання відповіді від AI-сервісу та забезпечення роботи налаштувань розширення. Текст сторінки передається зовнішньому сервісу лише в межах запиту, який запускає користувач.

06 Контроль користувача

  • Користувач самостійно обирає текст і запускає його обробку.
  • Користувач може не запускати AI-запит, якщо не бажає передавати текст до Groq.
  • Користувач може видалити збережений ключ API та налаштування через засоби керування розширенням або очищення даних розширення в Chrome.

07 Зміни до політики

Політика може оновлюватися у разі зміни функцій розширення або способів обробки даних. Актуальна редакція публікується на цій сторінці із зазначенням дати набрання чинності.
